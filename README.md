<h4>
SaaSoft тестовое задание. Стэк vue 3 / composition api / typescript / pinia стейт менеджер / Quasar UI framework and pinia persist plugin для автоматического хранения стейта в Local Storage
</h4>

Шаги:

1. Склонировать репозиторий: https://github.com/Chefchelious/SaaSoft.git

2. В корневой папке запустить команлу npm i для установки зависимостей

3. Запуск проекта командой npm run dev

Приложение автоматически откроется по адресу http://localhost:9000
Лайв-демо приложения на netlify https://saas-soft.netlify.app/
